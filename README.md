## How to

- Set app name

      dart run rename_app:main all="Tune Tangler"

- Regenerate icons:

      dart run flutter_launcher_icons

- Regenerate splash screen:

      dart run flutter_native_splash:create

- Build & install APK via ADB

      melos run apk
